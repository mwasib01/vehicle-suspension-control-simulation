# Vehicle Suspension Modelling and Active Control using MATLAB/Simulink


## Overview

This repository contains MATLAB/Simulink models developed for vehicle suspension dynamics analysis.

The project investigates passive and active suspension behaviour using quarter-car and half-car vehicle models. A PID-based active suspension controller is implemented and compared against passive suspension performance.

The objective is to analyse vehicle ride behaviour under different road disturbances and evaluate improvements achieved through active control.


---

# Project Features

- Quarter-car suspension modelling
- Half-car suspension modelling
- Passive suspension analysis
- Active suspension control using PID
- Road profile generation
- Suspension displacement analysis
- Vehicle body acceleration evaluation
- MATLAB/Simulink based simulation

# Suspension Models


## Quarter Car Model

The quarter-car model represents a simplified vehicle suspension system consisting of:

- Sprung mass
- Unsprung mass
- Suspension spring
- Damper
- Road excitation input


The model is used to evaluate suspension response and ride comfort.


---

## Half Car Model

The half-car model extends the system by including:

- Front suspension
- Rear suspension
- Vehicle body motion
- Pitch dynamics


This provides a more realistic representation of vehicle behaviour.


---

# Active Suspension Control

A PID-based controller is implemented to improve suspension response.

The controller adjusts actuator behaviour based on suspension motion feedback.

The objective is:

- Reduce body acceleration
- Improve ride comfort
- Limit suspension displacement


---

# Simulation Inputs

The models use generated road surface disturbances to evaluate suspension performance under different conditions.
